# employee-data-analysis
Employee data analysis using Python, Pandas, Matplotlib and Seaborn to explore employee demographics, departments, salaries and experience.


Employee Analysis Project 

Project Title

Employee Data Analysis Using Python

Description

This project focuses on analyzing employee data from 2020, 2021, and 2022 using Python. The main objective is to explore employee information, analyze department-wise employee distribution, salary patterns, experience, gender, and country-wise employee distribution.

Project Objective

- Analyze employee distribution across departments and positions.
- Understand gender-wise employee distribution.
- Analyze employee marital status.
- Identify highest salary across departments and positions.
- Analyze employee experience.
- Explore country-wise employee distribution.
- Visualize salary distribution and employee data.

Dataset

- Employee Dataset (2020)
- Employee Dataset (2021)
- Employee Dataset (2022)

Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

Features

- Data Loading and Combining
- Data Exploration
- Missing Value Analysis
- Duplicate Record Analysis
- Department-wise Employee Analysis
- Position-wise Employee Analysis
- Gender-wise Employee Analysis
- Marital Status Analysis
- Highest Salary Analysis
- Experience-wise Employee Analysis
- Country-wise Employee Analysis
- Salary Distribution Visualization
- Correlation Heatmap

Visualizations

- Bar Chart
- Pie Chart
- Histogram
- Correlation Heatmap

How to Run

1. Download the project notebook.
2. Open it in Google Colab.
3. Upload the 2020, 2021, and 2022 employee datasets.
4. Run all notebook cells.
5. Explore the analysis results and visualizations.

Conclusion

This project helped in understanding employee data through Exploratory Data Analysis (EDA). It provided insights into employee distribution, salary patterns, experience, and other employee-related information using Python libraries.
